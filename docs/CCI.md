# CCI｜旅行社獲客網站

**版本：**1.0｜**建立日期：**2026-11-27  
**依據：**課程提供的 CCI 定義、`docs/weekly-report.md`、`research/travel-data.json` 與 `research/sources.md`。本文件是規劃，不代表網站已上線或推薦方案已可銷售。

## Core｜核心

幫助旅客快速找到適合自己的旅遊行程。網站以旅客填寫的條件篩選旅行社已整理且資料狀態清楚的活動或行程，呈現推薦理由、來源和有效性資訊，讓旅客能進一步提出諮詢。

## Clear｜明確

旅客可選擇：

- **旅遊對象：**親子、情侶、熟齡旅客；可複選或選「尚未決定」。
- **預算：**每人新臺幣總預算（NT$/人），依全程預算輸入上下限；須說明是否含交通、住宿、餐食、門票等。目前素材未提供售價，方案價格皆顯示「待確認」，不作價格吻合承諾。
- **天數：**預計旅遊天數，以天為單位；活動資料未涵蓋完整行程天數時不推定。
- **旅遊風格：**從資料欄位化的主題選擇，例如科普體驗、地方文化、生態觀察、節慶燈飾、音樂表演、花卉、藝術裝置。這些主題來自本期週報，不代表使用者偏好統計。

以上偏好只在本次瀏覽器操作中用來產生建議；第一版不要求姓名、電話或電子郵件，也不連接 Supabase 或其他後端。諮詢若需聯絡資料，交由旅行社既有人工流程另行處理，納入前須確認個資告知與保存方式。

## Issue｜問題

行程太多、比較困難、不知道如何選擇。網站以少量條件先縮小候選，再逐項列出符合/不符合/未知的條件、推薦理由、來源與查詢日期；資料不足時清楚指出缺口，協助旅客帶著明確問題洽詢旅行社。

## 設計邊界

- 目前週報與資料集收錄官方活動資訊，不等於旅行社完整行程、可售商品或實際報價；不可把活動卡片稱為已確認可訂行程。
- 查詢日為 2026-11-27。日期已過的 2026 台中國際花毯節不得列為可參加推薦；花蓮鯉魚潭水岸光影節狀態為待確認，不作已核實推薦。
- 客群適配中，官方描述與研究判斷須分開標示。研究判斷只供參考，不保證適齡、無障礙、安全或適合個人。
- 顯示的偏好及推薦結果如使用虛構情境示例，顯眼標記「模擬資料」。
