# AI 台灣旅遊情報員 × 智慧行程推薦網站

以可追溯的台灣旅遊情報，整理親子、情侶與熟齡旅客可進一步洽詢的旅遊方向。這個 repository 同時保存研究紀錄、週報、簡報、影片素材及靜態推薦網站。

## 專案內容

| 路徑 | 內容 |
| --- | --- |
| `index.html` | 靜態旅遊提案網站，可依同行對象及旅遊風格篩選活動方向。 |
| `research/` | 活動資料集、來源紀錄與待確認事項。 |
| `docs/` | 產品需求、流程文件及每週旅遊情報。 |
| `presentation/` | 簡報大綱、HTML 投影片、PNG 頁面及 PPTX 成品。 |
| `video/` | 影片腳本、分鏡、製作程式、場景圖與 MP4 成品。 |
| `templates/` | 研究素材包與交接驗收模板。 |
| `AI台灣旅遊情報員/` | 核心規範、研究、週報與模板的整理副本；更新時請同步根目錄版本。 |
| `AGENTS.md` | 角色分工、交接流程、來源與驗收規範。 |

## 開啟網站

網站是單一靜態 HTML，無需安裝套件。可直接用瀏覽器開啟根目錄的 `index.html`。若想透過本機 HTTP 伺服器預覽，請在專案根目錄執行：

```powershell
python -m http.server 8000
```

再開啟 `http://localhost:8000/`。

## 資料使用與限制

- 外部資訊的來源與查詢日期記錄在研究資料、週報及網站活動資訊中；活動內容可能變動，出發或洽詢前請重新核對官方公告。
- 活動情報不等同旅行社可訂購商品。價格、完整行程天數、名額、場次、交通及包含項目若未有來源支持，均標示待確認。
- 客群適配可能屬研究判斷，不代表官方保證適齡、無障礙或適合個別旅客。
- 影片人物與情境畫面是模擬或示意素材，並非真實旅客或現地紀錄。
- 專案工作規範與逐項驗收方式請先閱讀 [AGENTS.md](AGENTS.md)。

## 憑證與個資

不得提交密碼、API Key、存取權杖、`.env` 或客戶個資。`.gitignore` 排除本機環境設定、憑證檔及常見暫存/建置目錄；若新增 `.env.example`，只放空值或假值。公開前仍應檢查提交內容與 Git 歷史，避免敏感資料進入版本紀錄。
